> [!IMPORTANT]
> to use Lazygit, first install in your terminal Lazygit (if you use Archlinux, you can use `sudo pacman -S lazygit`).

- gcc
- npm
- pnpm
- node
- python
- live-server
- unzip

> [!IMPORTANT]
> you need install live-server by npm.

To use **tailwindcss** if you want to work with the V4.1, you need install the **TailwindCLI**, 'cause nvim don't recognize the line <link> if you want to test designs in nvim.
